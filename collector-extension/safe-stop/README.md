# 순위 수집기 — 안전 중지판 (v1.12.0)

> **이 폴더는 「확실히 멈춰야 할 때」 쓰는 확장입니다. 수집을 하지 않습니다.**
> 만든 곳: 코덱스(Codex) · 대표 지시로 저장소에 보존 (2026-09-14)

## 왜 보존하나

2026-09-09~13 에 수집이 네이버에 막혀 며칠 세워 둬야 했다. 그때 **확장을 끄는 것만으로는
불안**했다 — 다시 켜지거나, 6시간 쉼이 풀린 뒤 자동으로 또 두드릴 수 있기 때문이다.
이 버전은 그 걱정을 **권한 수준에서** 없앤다.

⚠️ 이 파일들은 대표 컴퓨터에만 있었다. 저장소에 없으면 다음에 누가 폴더를 갈아 끼울 때
   **조용히 사라진다.** 그래서 원본 그대로 올려 둔다(한 줄도 고치지 않았다).

## 운영판(`collector-extension/`)과 무엇이 다른가

| | 운영판 v1.11.0 | **안전 중지판 v1.12.0** |
|---|---|---|
| `search.shopping.naver.com` 권한 | 있음 | **없음** |
| `tabs` · `scripting` · `alarms` 권한 | 있음 | **없음**(`storage` 만) |
| 수집 코드 | 있음 | **없음**(서비스 워커 51줄) |
| 「지금 수집 실행」 | 동작 | **거절**(`AUTOMATION_DISABLED`) |
| 하는 일 | 수집 | 서버 상태 조회(`/api/collector/status`) + 상태 표시 |

⇒ **실수로도 네이버를 긁을 수 없다.** 확장을 끄는 것보다 확실하다.

## ⚠️ 설치하면 확장에 쌓인 기록이 지워진다

`migrateStorage()` 가 **whitelist 방식**으로 정리한다. 남는 것은 이것뿐:

```
token · workerId · workerNo · workerCount · lastErrorCode(안전 코드만)
```

⇒ **팝업 로그 · 「🩺 마지막 판독 실패」 · 캡차 상태(`blockedUntil`) · 안전 속도(`slowUntil`) ·
   수집 원본 샘플이 전부 삭제된다.**

⚠️ **막힌 증거를 아직 안 읽었다면 설치 전에 먼저 읽을 것.**
   2026-09-14 에 실제로 9/12 캡차 증거가 이 청소로 지워졌다. 다행히 서버가 받아 둔
   `collector_blocks` 기록이 남아 있어 원인 분석은 지장이 없었다
   (그 서버 보고는 v1.10.8 에서 만든 것이다 — 그게 없었으면 증거가 통째로 사라졌다).

✅ 토큰과 기계 번호는 남으므로 **운영판으로 돌아갈 때 다시 입력할 필요가 없다.**

## 쓰는 법

**멈출 때** — 맥미니 확장 폴더에 이 폴더의 파일을 덮어쓰고 `chrome://extensions` 새로고침.
**다시 돌릴 때** — `collector-extension/` (운영판) 파일로 덮어쓰고 새로고침.

⚠️ **폴더 위치는 절대 옮기지 않는다.** 확장 ID 가 경로에서 나오므로, 자리를 옮기면
   크롬이 다른 확장으로 보고 **토큰이 사라진다.**
