## 승인과 범위

대표가 합성 미리보기를 확인한 뒤 「응 마음에 들어 진행해」로 운영 반영을 승인했다. 기존 운영 `6e4b035901027fef29266de218bfb0594227a3fe`에서 검증 제품 `e132a4b6ebba40ca58fb4de3cd3a66a3c910b218`로 관제 전용 엔진·중계만 교체한다. 이 문서는 준비와 실제 운영 결과를 구분한다.

- 이전 승인 기능: 같은 창의 조회 자료를 재사용하고 추가·수정·제외된 행만 반영한다. 화면 재진입마다 현재 권한을 확인하며, 네이버 수집을 새로 실행하지 않는다.
- 이번 화면: 이관 현황의 「전산 실관리·누락 대조」와 「이관 광고 계정 전체」를 버튼으로 전환한다. 두 표는 동시에 표시하지 않으며 요약 카드와 새로고침은 공통이다.
- 관제 「나에게 올라온」은 처음에는 접힌 상태로 건수를 표시한다. 펼침 선택은 같은 창의 화면 이동·자료 갱신에서 유지하고 로그인 종료·교체 시 초기화한다. 읽음·해결 상태를 자동 변경하지 않는다.
- 상품 원본·계정 연결·광고 설정·수집 정책·자동입찰·기존 전산/광고센터/로직/스튜디오는 변경하지 않는다.
