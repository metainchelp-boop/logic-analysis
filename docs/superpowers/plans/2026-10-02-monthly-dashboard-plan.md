# 월간 대시보드 구현 순서

기준: `eb3c9a8`. 설계: `../specs/2026-10-02-monthly-dashboard-design.md`.

1. 기존 담당 권한·카드 필터를 재현하고 전체보기 및 표/이슈/상향의 동일집합 필터를 시험부터 구현한다.
2. 별도 월간 저장/이어읽기와 기간별 집계를 구현한다. 전일 우선·같은 호출 예산·자정/권한/누락 방어를 시험한다.
3. 권한 적용 후 저장 원천만 읽는 대시보드 API, 새 화면 경로와 허용 목록을 연결한다. 부분합·업체별 평균·ROAS 분모·월1일을 시험한다.
4. 새 탭·대시보드 지표·수집범위/미확인 안내·모바일 화면을 구현하고 범위변경/느린응답 경합 시험한다.
5. 독립 안전/사양 검토, 전체 테스트 및 격리 Linux·브라우저 CI로 확인한다. 정확한 변경 파일만 커밋·개발 브랜치에 보관하며 배포는 별도 승인 전 실행하지 않는다.

기록: 구현 전 기존 미추적 `outputs/` 진단 파일은 보존하고 제품 변경 커밋에 포함하지 않는다. 단일 쓰기 잠금·속도 정책·운영 설정·기존 앱 배포 도구는 변경하지 않는다.
