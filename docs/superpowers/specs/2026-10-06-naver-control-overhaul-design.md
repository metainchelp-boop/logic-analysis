## 원인별 「할 일 한 줄」(D8 — 확정 문구)

이슈 줄은 지금 원인(`app.js` `CAUSE` 표)만 말한다. 같은 코드 열쇠로 「할 일」 표를 하나 더 두고, 줄마다 원인 아래에 한 줄로 보인다. 광고주 한 장(`/naver/clients/{번호}`) 맨 위에도 같은 한 줄.

| 이슈 코드 | 원인(지금 문구 그대로) | 할 일 한 줄 |
|---|---|---|
| `link_broken` | 🔌 이관이 빠졌습니다 | 광고주에게 네이버 검색광고 「대행사 관리」에서 우리 회사 연결이 남아 있는지 확인 요청 |
| `bizmoney_low` · `bizmoney_empty` | 비즈머니가 곧 바닥납니다 / 0원입니다 | 광고주에게 충전 요청(남은 날·하루 평균 광고비 함께 안내) |
| `active_no_impressions` | 켜져 있는데 광고가 안 나갑니다 | 네이버 광고 관리에서 노출 제한 사유(검수·입찰가·예산) 확인 |
| `spend_up` | 광고비가 갑자기 늘었습니다 | 광고주 기획전·예산 변경인지 확인 · 아니면 입찰가·키워드 점검 |
| `spend_down` | 광고비가 갑자기 줄었습니다 | 예산 소진·입찰 순위·광고 중지 여부 확인 |
| `running_zero_spend` | 진행중인데 광고비가 0원입니다 | 캠페인 꺼짐·잔액·검수 상태 확인 |
| `key_rejected` | 네이버가 읽기를 거절했습니다(이관은 남아 있음) | 광고주에게 우리 회사 권한(운영관리)이 바뀌었는지 확인 요청 |
| `spend_after_contract` | 계약 단계와 광고비가 맞지 않습니다 | 전산 계약 단계(환불중·만료) 확인 · 광고 중지 여부 광고주와 확인 |
| `period_ending` | 캠페인 기간이 곧 끝납니다 | 이어 갈지 광고주와 확인 |
| `budget_lock` ※ | 예산 잠금으로 광고가 멈췄습니다 | 광고주에게 비즈머니 예산 잠금이 걸린 까닭을 확인하고 풀어 달라고 요청 |
| `refund_lock` ※ | 환불 잠금이 걸려 있습니다 | 광고주가 비즈머니 환불을 신청했는지 확인 · 전산 계약 단계(환불중)와 맞는지 확인 |

※ 시안 초안 9줄에 없던 두 코드 — 같은 말투로 채웠다. 대표 보고 때 「고칠 문구가 있으면 말씀해 주십시오」로 알린다.
