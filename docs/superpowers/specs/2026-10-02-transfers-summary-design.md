# 이관 현황 요약 카드 — 승인된 설계

2026-10-02 대표가 제안된 6개 카드, 카드별 목록 연결, 담당 범위 적용을 승인했다.

- 현재 이관 총수 = 매칭 + 업체 미확인 + 미분류. 업체 미확인은 실제 미등록 확정이 아니다.
- 이관 빠짐은 현재 총수 밖의 과거 수락 계정 중 기존 `link_state`의 서로 다른 날짜 2일·20시간 조건을 만족한 계정이다. 한 번도 이관된 적 없는 번호는 포함하지 않는다. 이름 추측으로 직원에게 노출하지 않는다.
- 원천 계정/전산 목록이 오래되거나 실패하면 매칭·이관 빠짐·잔액 확정 표시를 보류한다. 알 수 없음과 0을 구분한다.
- 카드 수와 합계는 서버가 허용한 담당 범위 전체 기준이다. 검색·매칭·업무 필터는 아래 목록만 좁힌다. 담당자 변경 시 이전 카드와 목록을 즉시 지운다.
- 비즈머니는 현재 계정의 오늘 확인된 유한한 값만 중복 없이 합산한다. 일부 확인이면 ‘확인된 잔액 합계’와 확인 수/대상 수, 미확인 수를 표시한다. 0원과 미수집을 구분한다. 모두 확인했을 때만 ‘총 비즈머니’로 표시한다. 과거 이관 빠짐 계정의 잔액은 포함하지 않는다.
- 6개 카드는 전체/매칭/미확인/미분류/이관 빠짐/잔액 확인 목록으로 연결한다. 기존 밝은 화면·글꼴·색 체계를 유지하고 작은 화면은 줄바꿈한다.
- 기존 저장소의 계정 부재 이력과 읽기 결과만 사용한다. DDL·광고 변경·원본 수정·수집 주기/예산 변경 없음.
- 검증: 합계 분할/부분 잔액/0원/소수점/중복/낡은 원천/첫날 부재/20시간 경계/직원 범위/카드 이동/담당 전환/새로고침/오류 화면.

추가 문의 진단: `STATUS_FROM_AUDIT`는 재시작 후 감사 기록에서 결과만 복원했다는 표식이다. 원래 보류 코드는 현재 감사에 저장되지 않아 이 표식으로 실제 보류 원인을 단정할 수 없다. 전체 계정 수집과 기존 아침 점검/수동 요청은 별개다. 진단은 원천 수집의 정상 완료를 의미하지 않는다.
