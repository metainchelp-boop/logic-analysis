## 복구 계약

스키마8·SQL·마이그레이션은 그대로지만 `zero_ids`가 든 새 이어읽기 JSON은 구버전의 엄격 검증과 호환되지 않는다. **구버전 코드만 수동 원복하면 당일 미완료 계정이 중단될 수 있으므로 금지한다.**

기존 적용 경로가 수행하는 서비스 정지·쓰기 중단 확인 → 배포 전 DB 사본 → 새 소스 적용 절차를 유지한다. 실패 시 새 DB/sidecar는 복구 가능 상태로 격리하고 해당 배포 전 사본을 복원한 뒤 구버전을 기동한다. 복원 불일치 시 두 서비스는 중지 상태로 유지한다. 실패 이후 새로 얻은 수집 결과는 활성 DB에 남지 않을 수 있으므로 배포 전후를 구분해 보고한다.
