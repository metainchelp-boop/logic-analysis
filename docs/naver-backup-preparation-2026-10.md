관리·교체 승인 책임은 회사 GitHub 관리 계정이다. 환경의 허용 가지 제한은 설정/조회했으나 추가 인적 승인자 보호를 적용했다고 주장하지 않는다. 일반 repository Secret은 관리자가 다른 workflow에서 참조할 수 있다. GitHub Secret 조회→등록은 원자적 create-only API가 아니므로 외부 관리자의 동시 변경까지 차단하는 보장은 없다. 이 실행은 단독 발급·직전 이름 재조회·로컬 프로세스 잠금으로 수행했다. 다시 실행하면 이름 충돌로 중단하며 자동 교체하지 않는다.

보관과 주입은 별개다. 운영 `.env`, `ENV_FILE`, 소비 앱은 변경하지 않았다. 특히 로직의 기존 배포 workflow에는 새 SSO Secret 전달 경로가 아직 없어 후속 연결이 필요하다. 전산 지문 지속 주입 코드와 각 소비 코드의 선행 배포도 별도 게이트다.
