2026-09-22 배포 · 로직분석 「📊 쇼핑 순위 추적」 맨 위 · 수집기 v1.26.0

무엇이 생겼나

① 순위 추적 화면 맨 위 「🧭 수집기 운영」 — 오늘 몇 개 모았고 몇 개 남았는지, 기계(노트북)마다 마지막 신호가 언제인지, 서버에 못 올린 결과가 몇 건인지 한 장으로. 5분마다 스스로 새로고침.
② 수집기(확장) 팝업 「📤 미전송」 — 서버가 잠깐 죽어도 모은 결과를 버리지 않고 노트북 안에 두었다가 서버가 살아나면 자동으로 다시 보냅니다. 예전엔 그 자리에서 버렸습니다.
③ 관리자용 「⏹ 전체 중지 / ▶ 검토 후 전체 재개」·「설정 점검」 — 모든 노트북의 다음 회차를 한 번에 막고, 원인을 검토했다고 체크해야만 다시 켤 수 있습니다.

직원(담당자) — 볼 것 3가지

  • 오늘 완료 / 대상 — 오늘 몇 개 키워드가 저장됐는지. 「부분」은 막혀서 찾은 순위만 적은 것.
  • 상품 연결 확인 필요 — 상품 고유번호(nvMid)가 없어 「300위 밖」이 진짜인지 못 가르는 대상 수. 순위 추적 화면에서 「🔎 자동 찾기」로 채우세요.
  • 값이 「미확인」 — 못 잰 것이지 0 이 아닙니다. 관리자에게 알려 주세요.

수집 노트북 담당자 — 팝업 읽는 법

팝업에 보이는 줄뜻할 일
📤 미전송 3건 · 다음 재전송 14:05서버에 못 올린 결과 3건. 서버가 받으면 사라짐기다리면 됩니다. 급하면 「📤 미전송 다시 보내기」 한 번
📤 미전송 3건 · 검토 필요 2서버가 그 결과를 거절했거나 응답이 이상함「🧾 진단 파일」을 내려받아 관리자에게. 원인 확인 전엔 「🗑 검토 후 비우기」를 누르지 않습니다
⛔ 신호 끊김 40분크롬이나 확장이 안 도는 것크롬을 열고 팝업 「📡 지금 상태 서버에 보내기」
🧱 캡차 쉼네이버 퍼즐이 떠서 6시간 쉬는 중네이버쇼핑을 직접 열어 퍼즐을 푼 뒤 「지금 수집 실행」. 반복해서 누르지 않습니다

관리자 — 전체 중지와 재개

  • ⏹ 전체 중지: 모든 노트북의 다음 회차를 막습니다. 이미 시작한 키워드는 끝까지 갑니다.
  • ▶ 검토 후 전체 재개: 「원인을 검토했습니다」에 체크해야 버튼이 살아납니다. 체크 없이는 요청이 나가지 않습니다.
  • 설정 점검: 켜기 전에 무엇이 막는지 목록으로. 「서버 자동 배정 스위치 꺼짐」은 시간대 방식으로 도는 정상 상태일 수 있습니다.
  • 요청 처리 여부를 못 확인했다는 문구가 뜨면 자동으로 다시 보내지 않습니다. 새로고침으로 현재 상태를 보고 판단하세요.

바뀌지 않은 것

  • 「300위 밖」 표기 그대로. 순위 판정 규칙·시간당 상한(40)·캡차 6시간 쉼 그대로.
  • 수집기 토글 「🧭 서버 자동 배정」은 기본 꺼짐 — 서버 스위치를 켜기 전까지는 종전 시간대 방식으로 돕니다.
  • 퍼즐은 사람만 풉니다. 다른 회선·다른 노트북으로 우회하지 않습니다.
