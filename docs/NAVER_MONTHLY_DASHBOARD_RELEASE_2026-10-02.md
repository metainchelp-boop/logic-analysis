## 이관과 복구

schema8→9는 기존 SQL을 그대로 보존하고 월간 표와 색인을 추가한다. 정확한 승인 소스·허용 경로·저장소 계약을 검증하며 임의 스키마 변경은 허용하지 않는다. 서비스 정지와 쓰기 중단 확인 뒤 schema8 일관 사본을 생성하고 검증한 후에만 새 코드가 DB를 연다.

실패 시 새 DB와 sidecar를 복구 가능한 격리 위치로 옮기고 배포 전 사본과 이전 코드를 함께 복구한다. 새 코드에서 수집한 결과는 복구 DB에 없을 수 있으므로 별도로 보존된 실패 DB와 구분한다. **이전 이미지만 수동 원복하지 않는다.** 복구 검증 실패 시 두 서비스는 중지 상태로 유지하며 보호 조건을 완화하지 않는다.
