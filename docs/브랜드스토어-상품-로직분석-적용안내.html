METAINC · 신고 #246

브랜드스토어 상품도
같은 로직분석 흐름으로

일반 스마트스토어에서 사용하던 방식은 그대로 두고, 네이버 브랜드스토어 상품 페이지에서도 수집·전송·분석·상품 매칭·점수 판정까지 이어지도록 개선했습니다.

v1.2.0 · 구현 및 사전검증 완료 · 운영 반영 대기

무엇이 바뀌나요?

상품 페이지 인식brand.naver.com과 모바일 브랜드스토어 상품에서 우측 분석 패널이 표시됩니다.
상세값 분석상품명·가격·카테고리·리뷰수·평점을 브랜드스토어 구조에서도 읽습니다.
같은 평가 기준일반·브랜드스토어 모두 네이버 스토어로 판정해 매칭과 신뢰도 점수 차이를 없앴습니다.

직원 PC 적용 순서

운영 배포 완료 안내를 받은 뒤 진행하세요. 서버만 배포해도 확장 파일은 자동 갱신되지 않습니다.
  1. 1전달받은 METAINC 로직분석 수집기 v1.2.0 폴더로 기존 확장 폴더의 파일을 교체합니다.
  2. 2크롬 주소창에 chrome://extensions를 입력합니다.
  3. 3METAINC 로직분석 수집기 카드의 새로고침(↻)을 누릅니다.
  4. 4열려 있던 브랜드스토어 상품 페이지도 새로고침합니다.
  5. 5확장 팝업 우측 상단이 v1.2.0, 현재 페이지가 네이버 스토어 상품 ✓인지 확인합니다.

정상 작동 확인

  • 브랜드스토어 상품 페이지 오른쪽에 파란 분석 패널이 1개 표시된다.
  • 키워드 입력 후 전송하면 로직분석 탭이 열리고 자동 분석이 시작된다.
  • 상품명, 가격, 카테고리, 리뷰수, 평점이 빠짐없이 표시된다.
  • 같은 판매자의 다른 상품이 아니라 현재 상품 ID가 우선 매칭된다.
  • 일반 스마트스토어에서도 기존과 동일하게 작동한다.

문제가 있을 때

패널이 안 보임확장 버전이 v1.2.0인지 확인 → 확장 카드 새로고침 → 상품 페이지 새로고침 순으로 다시 확인합니다.
상품 페이지 아님 표시주소가 brand.naver.com/스토어명/products/숫자 형식인지 확인합니다. 홈·리뷰·검색 페이지에서는 의도적으로 동작하지 않습니다.
전송 후 값 누락상품 주소, 확인 시각, 누락된 항목을 함께 신고합니다. 임의로 다른 상품을 대신 등록하지 않습니다.
긴급 되돌림기존 v1.1.2 폴더로 되돌린 뒤 확장 카드와 상품 페이지를 새로고침합니다. 브랜드스토어만 다시 비활성화되고 일반 스마트스토어 흐름은 복구됩니다.
