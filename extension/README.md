# METAINC 로직분석 수집기 (크롬 확장)

스마트스토어 상품 페이지를 자동 스크롤로 완전 수집해 로직분석으로 원클릭 전송한다.
북마클릿의 대체·보완 수단이며, 기존 북마클릿·HTML 붙여넣기 흐름은 그대로 유지된다.

## 설치 (선행 사용 / 개발자 모드)
1. 크롬 주소창 `chrome://extensions` → 우상단 "개발자 모드" ON
2. "압축해제된 확장 프로그램을 로드" → 이 `extension/` 폴더 선택
3. 스마트스토어 상품 페이지 접속 → 우하단 파란 패널에서 키워드 입력 → 보내기

## 동작 흐름
상품 페이지 FAB → ①자동 스크롤(리뷰·상세 lazy 전부 로드) → ②완전 수집(자가 검증) →
③chrome.storage 보관 + 로직분석 탭 오픈 → content-logic.js 가 앱에 postMessage →
앱이 검색바에 자동 주입·분석 자동 시작(키워드 포함 시). 앱 ACK 시 보관물 삭제.

## 무해 실패 원칙
- 어떤 실패도 기존 흐름을 막지 않는다: 실패 시 패널에 안내 + 북마클릿 폴백.
- 30KB 미만(비정상) 수집물은 전송 자체를 차단.
- 10분 지난 수집물은 자동 폐기. 로그인 전이면 유효시간(10분) 동안 2초 간격 재시도 + 로그인 화면에 대기 안내 배너 표시. (v1.0.1)
