네이버 관제

읽기 전용 검증판입니다. 기존 권한 범위 안의 자료만 보이며 광고·업무 변경·자동입찰·알림 전송은 꺼져 있습니다. 대표는 검증된 계정의 연결을 확정하고 즉시 조회할 수 있습니다. 아침 점검은 예약 시각에 실행되므로 현재 시간대에는 미수집·미점검일 수 있습니다. 자료 기준 시각을 확인해 주세요. 미점검은 정상 판정이 아닙니다.

🛰 관제

내 권한 범위의 네이버 광고 점검 결과입니다. 「확인 필요」와 「점검 불가」를 함께 확인해 주세요. 자료 반영 전이나 미점검 상태는 정상 판정이 아닙니다.

광고를 변경하지 않고 현재 연결된 관리 대상만 조회합니다.

오늘의 이슈

원인별로 묶었습니다 · 🔴 긴급은 풀릴 때까지 「확인 필요」에 남습니다

🔗 짝 확인

이 광고주 광고계정이 맞는지 사람이 확인합니다 · 확인 전에는 자동화·광고주 보고서가 켜지지 않습니다

📦 계약 끝난 광고주

기존 계약 점검은 종료 14일까지 · 전체 이관 계정은 「이관 현황」에서 확인합니다
›

🤖 자동화

광고주별로 자동 운영을 켜고, 엔진이 한 일을 확인하고, 되돌리는 곳입니다. 관제(점검·이슈)와 따로 있습니다.

5차에 엽니다. 관제(2차) → 구조 점검·알림(3차) → 보고서(4차)를 먼저 만들고, 자동화는 시험 계정으로 실증한 뒤 엽니다. 지금 관제는 네이버 계정을 읽기만 합니다.

📄 보고서

광고주별 주간·월간 네이버 광고 보고서입니다. 매주·매월 저절로 만들어지고, 게시하면 전산 광고주 공유 화면에 링크로 올라갑니다.

4차에 엽니다. 아침 점검이 쌓은 기록(광고비·노출·클릭·이슈 기록)이 보고서 재료가 됩니다. 「계정 확인 전」 광고주는 보고서를 만들지 않습니다.

📋 이관 현황

선택한 담당 범위의 현황입니다. 카드를 누르면 아래 목록을 해당 조건으로 볼 수 있습니다.

이관 광고 계정 전체

회사에 이관된 계정을 기준으로 전산 업체와 연결합니다. 매칭 상태·업무 단계·수집 결과는 서로 다른 정보입니다. 관리직원은 본인 담당 계정만 보입니다.

광고 계정 · ID전산 업체매칭 상태업무 단계담당수집 결과어제 광고비비즈머니

전산에 번호를 입력할 곳: 광고주 관리 → 업체 계정 정보 → 네이버 관제용 광고 계정 ID. 기존 API 고객 ID나 비밀키는 바꾸지 않습니다.

수집 대기: 오늘 아직 수집하지 않은 계정 · 재시도 대기: 수집을 시도했지만 완료하지 못한 계정입니다. 아침 점검의 처리 수와 전체 이관 계정의 수집 완료 수는 다릅니다.
