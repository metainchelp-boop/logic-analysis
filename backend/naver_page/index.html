네이버 관제

기존 담당 권한 범위 안의 자료만 보입니다. 서버에서 허용한 계정 연결·관제 포함/제외·조회·보고서 검토만 할 수 있으며, 네이버 광고 변경·자동입찰·외부 전송은 꺼져 있습니다. 예약 전에는 미수집·미점검일 수 있습니다. 자료 기준 시각을 확인해 주세요. 미점검은 정상 판정이 아닙니다.

📊 월간 대시보드

월초부터 어제까지, 현재 권한 범위의 광고 성과입니다. 확인하지 못한 자료는 0으로 표시하지 않습니다.

어제 실제 집행

어제 실적 없음은 노출·클릭·광고비가 모두 0으로 확인된 상태이며, 캠페인 설정 중지를 뜻하지 않습니다.

광고 설정 상태

설정상 운영 가능은 실제 집행되었다는 뜻이 아닙니다. 운영 가능 캠페인이 없는 이유에는 상태·잠금·기간 등이 포함될 수 있습니다.

월간 자료는 기존 수집 예산에 여유가 있을 때 채워집니다. 새로고침은 저장된 자료만 다시 읽으며, 광고나 수집 설정을 변경하지 않습니다.

🛰 관제

내 권한 범위의 네이버 광고 점검 결과입니다. 「확인 필요」와 「점검 불가」를 함께 확인해 주세요. 자료 반영 전이나 미점검 상태는 정상 판정이 아닙니다.

광고를 변경하지 않고 현재 연결된 관리 대상만 조회합니다.

기존 계약 점검은 종료 14일까지 · 전체 이관 계정은 「이관 현황」에서 확인합니다

🤖 자동화

광고주별로 자동 운영을 켜고, 엔진이 한 일을 확인하고, 되돌리는 곳입니다. 관제(점검·이슈)와 따로 있습니다.

5차에 엽니다. 관제(2차) → 구조 점검·알림(3차) → 보고서(4차)를 먼저 만들고, 자동화는 시험 계정으로 실증한 뒤 엽니다. 지금 관제는 네이버 계정을 읽기만 합니다.

📄 보고서 · 담당 검토

확정된 계정의 주간·월간 실적입니다. 생성·집계 상태와 담당 검토는 별개입니다. 승인해도 광고주에게 게시하거나 전송하지 않습니다.

📋 이관 현황

선택한 담당 범위의 현황입니다. 카드를 누르면 아래 목록을 해당 조건으로 볼 수 있습니다.

전산 실관리 업체 · 계정 누락 대조

진행중 · 사후관리 · 전략관리 · 재계약진행중 업체가 기준입니다. 계정이 아직 연결되지 않은 업체도 포함합니다. 아래 계정 목록의 검색·필터와 별도로 현재 담당 범위를 대조합니다.

전산 업체 · 단계계정 확인 상태연결 / 전체 후보확인할 곳

번호 입력: 광고주 관리 → 업체 계정 정보 → 네이버 관제용 광고 계정 ID. 기존 API 고객 ID나 비밀키는 변경하지 않습니다. 번호 충돌은 대표에게 확인을 요청해 주세요.

이관 광고 계정 전체

회사에 이관된 계정을 기준으로 전산 업체와 연결합니다. 매칭 상태·업무 단계·수집 결과는 서로 다른 정보입니다. 관리직원은 본인 담당 계정만 보입니다.

광고 계정 · ID전산 업체매칭 상태업무 단계담당수집 결과확인된 실적 · 기간비즈머니 · 확인 시각관제 관리

전산에 번호를 입력할 곳: 광고주 관리 → 업체 계정 정보 → 네이버 관제용 광고 계정 ID. 기존 API 고객 ID나 비밀키는 바꾸지 않습니다.

실관리 4단계는 일일 점검, 그 외·수동 제외 계정은 일요일에 완료된 최근 7일을 점검합니다. 수집 대기는 아직 조회 전, 재시도 대기는 조회를 완료하지 못한 상태입니다. 이전 성공값은 표시된 실적 기간의 값이며 현재 상태를 뜻하지 않습니다. 비즈머니는 확인 시각의 잔액으로, 증감만으로 충전을 판단하지 않습니다.
