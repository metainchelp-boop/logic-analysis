광고 설정 상태

설정상 운영 가능은 실제 집행되었다는 뜻이 아닙니다. 운영 가능 캠페인이 없는 이유에는 상태·잠금·기간 등이 포함될 수 있습니다.

전일 실적은 00:01부터 수집하고 10:00 출근용 집계를 목표로 합니다. 미완료 자료는 이후에도 계속 수집하며, 늦게 바뀐 실적은 재확인 후 정정합니다. 새로고침은 저장된 자료만 다시 읽으며 광고나 수집 설정을 변경하지 않습니다.

🤖 자동화

광고주별로 자동 운영을 켜고, 엔진이 한 일을 확인하고, 되돌리는 곳입니다. 관제(점검·이슈)와 따로 있습니다.

5차에 엽니다. 관제(2차) → 구조 점검·알림(3차) → 보고서(4차)를 먼저 만들고, 자동화는 시험 계정으로 실증한 뒤 엽니다. 지금 관제는 네이버 계정을 읽기만 합니다.

바로 보기 · — 네이버 「대행사 관리」에서 연결을 풀어 달라고 광고주에게 요청할 곳입니다. 계약이 끝나면 매일 점검에서 빠지며, 현재 이관 계정의 비관리 주간 관찰은 별도로 이어집니다.

전산 실관리 업체 · 계정 누락 대조

진행중 · 사후관리 · 전략관리 · 재계약진행중 업체가 기준입니다. 계정이 아직 연결되지 않은 업체도 포함합니다. 「이관 광고 계정 전체」의 검색·필터와 별도로 현재 담당 범위를 대조합니다.

전산 업체 · 단계계정 확인 상태연결 / 전체 후보확인할 곳

번호 입력: 광고주 관리 → 업체 계정 정보 → 네이버 관제용 광고 계정 ID. 기존 API 고객 ID나 비밀키는 변경하지 않습니다. 번호 충돌은 대표에게 확인을 요청해 주세요.

이관 광고 계정 전체

회사에 이관된 계정을 기준으로 전산 업체와 연결합니다. 매칭 상태·업무 단계·수집 결과는 서로 다른 정보입니다. 관리직원은 본인 담당 계정만 보입니다.

비즈머니 높은 순 · 미확인 잔액은 마지막에 표시합니다.

광고 계정 · ID전산 업체매칭 상태업무 단계담당수집 결과확인된 실적 · 기간비즈머니 · 확인 시각관제 관리

전산에 번호를 입력할 곳: 광고주 관리 → 업체 계정 정보 → 네이버 관제용 광고 계정 ID. 기존 API 고객 ID나 비밀키는 바꾸지 않습니다.

실관리 4단계는 00:01부터 전일 실적을 수집하고, 10:00 목표 뒤에도 미완료를 계속 수집합니다. 그 외 이관 계정은 일요일에 완료된 최근 7일의 주간 관찰을 시작하고 미완료를 이어서 수집합니다. 수집 대기는 아직 조회 전, 네이버 집계 대기는 원천 준비 전, 재시도 대기는 조회 오류 뒤 다시 확인할 상태입니다. 이전 성공값은 표시된 실적 기간의 값이며 현재 상태를 뜻하지 않습니다. 비즈머니는 확인 시각의 잔액으로, 증감만으로 충전을 판단하지 않습니다.

연결 한 번에 확정

이름과 광고 계정 번호가 모두 맞는 곳만 「이 계정 맞음」으로 기록합니다. 확정하면 그 계정으로 매일 점검하고 보고서를 만듭니다. 광고는 바꾸지 않습니다. 잘못 확정한 곳은 짝 확인 목록의 「거두기」(대표님만 · 사유 필수)로 판단을 거둘 수 있습니다.

관제 관리 변경

전산 단계나 네이버 광고를 바꾸지 않습니다. 포함하면 일일 점검, 제외하면 일요일 7일 점검 대상이 됩니다. 단계가 바뀌면 기존 선택은 다시 확인합니다.

실적 기간 재확인

한국시간 어제까지, 한 번에 최대 31일의 저장 실적을 원천과 다시 대조합니다. 조회 요청일 뿐 즉시 완료를 뜻하지 않으며, 네이버 광고를 변경하지 않습니다. 늦게 반영된 값이 있으면 관련 보고서도 정정됩니다.
